# 🥞 Retro Recipe & AI Productivity Assistant

A unique, Y2K/coquette-aesthetic web application built for the hackathon that combines a smart AI-powered recipe parser with a general productivity assistant, powered by NVIDIA models via **Nebius Token Factory**.

---

## ✨ Key Features
- **Smart Recipe Parser**: Paste any social media recipe link or raw ingredient list to instantly extract structured steps, cooking time, ingredients, and chef's tips.
- **General AI Productivity Assistant**: Get instant help with study plans, coding, and daily organization.
- **Custom Y2K Aesthetic**: Designed with a nostalgic 3-column retro layout, complete with custom moodboards, a Spotify playlist, and a calendar widget.
- **Powered by NVIDIA & Nebius**: Utilizes `meta-llama/Llama-3.3-70B-Instruct` through the high-performance Nebius Token Factory API.
